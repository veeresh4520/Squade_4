## Scenario
A learner prints the first five multiples of a chosen number. The current sample values are already present in the Java file. Make the program produce the result required below.

## Task
At a small bank desk, the program is used for a short beginner exercise. Make it follow the stated rule for the supplied values. Keep the solution within basic Java syntax, variables, conditions, loops, arrays, strings, and simple methods.

## Expected output
```text
9 x 1 = 9
9 x 2 = 18
9 x 3 = 27
9 x 4 = 36
9 x 5 = 45
```

## Completion criteria
